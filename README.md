# What Is This?

*Sacred Opal* is an in-development Twine game (Harlowe 3.3.9), written with Visual Studio Code and complied using Tweego.

# How to Setup the Game?

Instruction on PC:
1. Download 2 things from this repo.
    1. The main game HTML [Opal_VS.html](Opal_VS.html);
    2. The "Asset" folder (make sure it is uncompressed).
2. Place the HTML right outside of the "Assets" folder. So:
    - 📁 any-folder
        - 📁 Assets
        - 📄 Opal_VS.html
3. Open Opal_VS.html with any browser.

# How to Play the Game

The only game-action consists of reading and clicking on links.

The game is not in a playable state right now. There is no on-boarding or tutorial. It is merely a demonstration of code for myself.

To begin playing the "game":
1. Open Opal_VS.html with any browser;
2. Click the "▶️ Play for realisies" link;
3. You should see the game content displayed;
4. Click around and see how quickly you run into a bug.
